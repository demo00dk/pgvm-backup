# pgvm-backup

This page is the homepage and privacy policy of pgvm-backup, a personal backup tool used by a single researcher for a PostgreSQL / pgvector index-maintenance study.

## What it does

It uses rclone with the Google Drive scope drive.file to copy experiment results from the researcher's own measurement server to the researcher's own Google Drive.

## Privacy policy

The app can only see and create files that it uploaded itself (Google Drive scope drive.file). It cannot read any other files in the Drive.

No personal data is collected, stored, sold or shared with anyone. The only data handled are research measurement files, and they go only to the researcher's own Google Drive.

The app has a single user (the researcher) and is not offered to anyone else.

Contact: open an issue in this repository.
